# SwiftEase Logistics

A modern and responsive logistics website designed to showcase delivery and logistics services while providing customers with a clear, intuitive, and professional digital experience.

**Live Website:** https://swift-ease.vercel.app/

---

## Features

* Responsive and mobile-friendly design
* Modern logistics-focused UI
* Service showcase
* Company information
* Delivery and logistics solutions
* Call-to-action sections
* Contact and inquiry sections
* Smooth animations and interactive elements
* Optimized navigation and user experience

---

## Getting Started

Clone the repository:

```bash
git clone https://github.com/webfyredev/SwiftEase.git
```

Navigate into the project:

```bash
cd SwiftEase
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open **http://localhost:5173** in your browser.

---

## Build for Production

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
